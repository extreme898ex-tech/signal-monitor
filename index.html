GitHubに直接保存する（初回だけトークン設定）
トークンの作り方： GitHub → 右上の自分のアイコン → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。リポジトリは signal-monitor だけを選び、Permissions で Contents: Read and write（保存後に自動実行もしたい場合は Actions: Read and write も）にして発行します。トークンは GitHub以外には送られません（このページから api.github.com へ直接通信します）。
